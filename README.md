# Git Practice Repository

This repository is created for practicing basic Git and GitHub commands.  
It includes multiple files, commits, and examples to demonstrate version control operations.

## Files Included
- `README.md`: Repository overview
- `.gitignore`: Files and folders to be ignored by Git
- `app.py`: Simple Python example script
- `notes.md`: Notes about Git commands
- `data/sample.txt`: Example data file

## Purpose
The goal is to learn how to:
1. Initialize a repository
2. Make commits
3. Push to GitHub
4. Use .gitignore
5. Keep sensitive data safe
